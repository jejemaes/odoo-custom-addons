# x_rental

## Set up product

Configure rental prices per day. Product should be a "service".
Pricelist is not supported.

Link resources to the rental product.

## From Sale Order

Add a rental sale order line, using the button link below Sale lines on Sale Order Form.
On confirmation, it will generate rental booking matching the dates and selected resources.

## From Rental Request

A rental booking can be created in "request" status. From there, you can create a Sale Order.
When a rental request is created, any partner with the tag "Rental Team" will be added as follower to be notified that a new request has arrived (This can be created through a website form that is not implemeted in this module).
